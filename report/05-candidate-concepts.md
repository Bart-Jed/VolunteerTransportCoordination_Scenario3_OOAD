## Key Decisions

- Journey request and Journey kept separate, as Journey request is the journey information awaiting for allocation, and Journey is the actual journey that is underway.
- Driver Check was kept as a class rather than an attribute because there can be several checks per driver with each of their own types and expiry.
- Offer was kept as a class even though it is basically an event because there can be several offers per journey, with each having their own status
- Destination was kept as an attribute despite the inconsistency problem because inconsistent descriptions are a data-quality issue.
- Kerry Community Link was removed because it has no information that the model needs.
